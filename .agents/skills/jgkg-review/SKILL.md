# JGKGレビュー

AGENTS.md と docs/codex-development.md の統制を確認する。パスはリポジトリルート基準。
対象仕様・関連裁定の最新訂正を読んでから差分を見る。
実装者の要約ではなくコード・テスト・一次記録で判定する。

- URIの永続性、名前付きグラフ置換、出典・取得日、SHACL/CQの意味を維持しているか。
- 生成元と生成物、APIとフロントの読み方、コンテナに含まれるファイルが整合するか。
- テストが変更対象の実経路に届くか。空の結果や常に通る条件で成功していないか。
- 実データ・HTTP・ブラウザのどの層を確認したか。未確認を全体の成功に拡張していないか。
- ステージ差分・外向きコミットに他作業が混入していないか。

指摘は再現条件、影響、場所、必要な修正を添える。壊し確認は隔離コピーか退避で行う。
修正後は該当指摘の解消を再確認する。自己レビューしか行っていない場合はその事実を明記する。
