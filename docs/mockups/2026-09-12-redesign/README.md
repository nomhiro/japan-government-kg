# フロント再設計の骨格モック(2026-09-12。レビュー済み・決定済み)

利用者が3つの骨格案と3つの視覚トーンを**見比べて選ぶ**ために作った静的モック。
設計キャンバス(Claude Design のアートボード形式 `.dc.html`)からそのまま保存したもので、
ブラウザで直接開いても概ね描画される(`support.js` の参照は無視してよい)。

| ファイル | 内容 |
|---|---|
| `Main.dc.html` | 案A-1 トップ「全体を見る」(把握の層) |
| `AEntity.dc.html` | 案A-2 事業ページ(型別ダッシュボード。追跡の層) |
| `DirectionB.dc.html` | 案B グラフ中心の探索ワークベンチ |
| `DirectionC.dc.html` | 案C 問い駆動(質問が入口) |
| `Tones.dc.html` | 視覚トーン3種(編集的・紙面 / 公共・明快 / データツール)を同じ部品で比較 |
| `canvas.json` | キャンバス上の配置と、各案の強み・弱みを書いた付箋 |

**決定(裁定B104・B105)**: 骨格は案Aの階層(把握→追跡→探索)に案Bのワークベンチを
第3層として組み込み、案Cの「よくある問い」カードと答えの組み立て方を取り込む。
トーンはデジタル庁デザインシステムを参考にした見やすさ・操作しやすさ優先。
仕様は `docs/superpowers/specs/2026-09-12-frontend-redesign-design.md`。

**数字はすべて実測値**(`docs/mockups/mock-data.js` と本番画面から)。取れていない値は
`[角括弧]` で明示し、架空の政府データは1件も含まない。
