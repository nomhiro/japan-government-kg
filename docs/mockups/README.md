# UIモック（実装前のレビュー用）

本開発の前にレビューするための、動くHTMLモック。

| ファイル | 中身 |
| --- | --- |
| `top-page.html` | 初期画面（`#/`）の案。ブラウザで直接開けます |
| `mock-data.js` | 表示データ。**自動生成物。手で編集しない** |

## 開き方

```sh
python -m http.server 8791 --directory docs/mockups
# → http://127.0.0.1:8791/top-page.html
```

`file://` で直接開いても動きますが、ブラウザの設定によっては
`mock-data.js` の読み込みが止まるためHTTPで開くほうが確実です。

## データの出どころ

**架空の政府データは1件も含みません。**

- ノードと関係: 本番API `/neighborhood/budget/2025/2840?depth=2` が返した
  57ノードを、読みやすさのため28ノードに間引いたもの
- 型ごと・関係ごとの件数: `data/artifact/2026-08-28-d2-recipient-category-v2/kg.nq`
  （884,053行）を全走査した実測値。**実現していない関係は描いていない**
- 支出の金額・未解決参照の元の記述: 同じ成果物から直接取得

ただし**支出と未解決参照の表示名だけは表示の提案として差し替えて**います
（原の値は `kgLabel` に残し、画面上でも明示しています）。理由はモック本文の
「レビューで決めたいこと」を参照。

## 本番との違い

モックは依存を増やさないため自前のSVG＋簡易フォースレイアウトで描いています。
本番は Sigma.js（WebGL）です。**Sigma.jsはCSSを読まない**ため、ラベル色は
`settings.labelColor` で明示する必要があります（`frontend/src/graph-theme.ts`）。
