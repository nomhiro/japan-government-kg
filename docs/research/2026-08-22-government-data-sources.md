# 日本政府公開データソースカタログ(KG構築用・2026年8月調査)

> 調査日: 2026-08-22。URLはすべて実在確認済み(未確認箇所は明記)。
> 本カタログは要求詳細化のための調査資料。承認済み仕様ではない。

## 収集の全体像(3層分類)

**①機械可読性が高くAPIで取れる層(KG構築の基盤)**
e-Gov法令API v2 / e-Stat API 3.0 / 統計LOD(SPARQL) / e-GovデータポータルCKAN API / 国会会議録API / EDINET API v2 / gBizINFO REST API / 法人番号Web-API / 官公需情報検索API / 特許情報取得API(試行) / NDLサーチSRU・OAI-PMH / 国立公文書館OAI-PMH / ジャパンサーチSPARQL / 不動産情報ライブラリAPI / アドレス・ベース・レジストリ / 気象庁JSON(非公式)。
特にKGネイティブ(RDF/SPARQL提供)なのは**統計LOD**と**ジャパンサーチ**の2つ。gBizINFOのSPARQLは2024年4月に廃止済み。

**②構造化されているがバルクDL/スクレイピングが必要な層**
法人番号全件CSV / 財務省予算書・決算書DB(XML) / 行政事業レビューRSシステム(CSV) / 登記所備付地図(XML) / 国土数値情報(GeoJSON等一括DL) / 地理院タイル / 衆参議員一覧・質問主意書(HTML) / 閣議決定一覧(HTML) / e-Govパブコメ(HTML) / 調達ポータル(HTML)。

**③PDF等非構造化文書の層(LLM抽出パイプラインが必要)**
官報(PDF) / 白書 / 審議会資料 / 裁判例(HTML+PDF) / 政治資金収支報告書(PDF、一部スキャン画像) / 各府省幹部名簿(PDF)。

## ライセンス警告(可視化アプリでの再配布に制約が出るもの)

- **国土数値情報**: データセット単位で利用条件が異なり「非商用」条件のものはアプリ組込・再配布不可。全体はPDL1.0(公共データ利用規約第1.0版)だが個別確認必須。
- **地理院タイル**: 基本測量成果に該当するタイルは測量法に基づく複製・使用承認が必要な場合あり。
- **官報**: 無料閲覧・DLは発行後原則90日間のみ。それ以降は有料の官報情報検索サービス。アーカイブ再配布は規約要確認。
- **裁判例**: 判決文自体は著作権法13条により著作権保護の対象外(再利用可)だが、最高裁サイトは政府標準利用規約の適用対象外(行政府の規約のため)でAPIも無く、スクレイピングポリシーは要確認。
- **J-PlatPat/特許情報取得API**: 試行提供でアクセス数上限・利用者登録必須。バルクデータの有償/無償区分は要確認。
- **政治資金収支報告書**: 公表期間が限定される運用(総務省分は公表後の掲載期間に注意、要確認)。永続アーカイブは自前保全が必要。
- **RESAS**: APIは2025年3月24日に提供終了。サイトからのCSV DLのみ。
- **気象庁JSONエンドポイント**: 非公式(仕様変更リスク)。データ自体の利用は政府標準利用規約準拠で問題なし。

## ソースカタログ

### A. 法令・国会・司法

**1. e-Gov法令検索 / 法令API Version 2**
- 検証済みURL: https://laws.e-gov.go.jp/ (API仕様: https://laws.e-gov.go.jp/api/2/swagger-ui)
- 提供主体: デジタル庁
- アクセス方式: API(REST、登録不要)。OpenAPI仕様公開
- データ形式: XML/JSON(法令標準XMLスキーマ)
- ライセンス: 政府標準利用規約(第2.0版)準拠。CC BY 4.0互換、商用・再配布可
- 更新頻度: 随時(法令の公布・施行に応じて)
- KG化の価値: 法令・条文・改正関係・委任関係のコアエンティティ。v2(2025年3月14日リリース)は時点指定検索・廃止法令検索・全文ファイルDLに対応し、法令の時系列バージョン管理がKGで表現可能。v1は将来廃止予定のためv2を採用すべき

**2. 日本法令索引**
- 検証済みURL: https://hourei.ndl.go.jp/
- 提供主体: 国立国会図書館
- アクセス方式: HTML中心(API提供の有無は未確認)
- データ形式: HTML
- ライセンス: NDLサイト利用規約(出典明示で利用可)
- 更新頻度: 随時
- KG化の価値: 明治19年以降の法令の改廃経過・法案の審議経過。「法案→審議→成立→改正」のライフサイクル関係がe-Gov法令(現行本文)を補完する

**3. 国会会議録検索システムAPI**
- 検証済みURL: https://kokkai.ndl.go.jp/api.html
- 提供主体: 国立国会図書館
- アクセス方式: API(HTTP GET、登録不要、1リクエスト最大100件)
- データ形式: XML/JSON
- ライセンス: NDL規約。国会での演説・陳述は著作権法上利用可能
- 更新頻度: 会議録作成後随時(会議から数日〜数週間)
- KG化の価値: 発言者(議員・大臣)-会議-発言-日付の関係。法案審議と人物をつなぐハブ。姉妹版として帝国議会会議録検索システムAPIも提供

**4. 衆議院・参議院サイト(議員一覧・議案・質問主意書)**
- 検証済みURL: 衆: https://www.shugiin.go.jp/Internet/itdb_annai.nsf/html/statics/syu/giinselect_m.htm / 参: https://www.sangiin.go.jp/japanese/joho1/kousei/giin/current/giin.htm / 質問主意書(参): https://www.sangiin.go.jp/japanese/joho1/kousei/syuisyo/218/syuisyo.htm
- 提供主体: 衆議院・参議院
- アクセス方式: HTMLスクレイピングのみ(公式API・CSV無し)
- データ形式: HTML(質問主意書・答弁書は本文HTML)
- ライセンス: 各院サイトの利用規約(立法府のため政府標準利用規約対象外、出典明示原則)
- 更新頻度: 国会回次ごと・異動随時
- KG化の価値: 議員(会派・選挙区・当選回数)エンティティのマスター。質問主意書-答弁書は議員と政策テーマを結ぶ一次資料。第1回国会以降全て公開(参)

**5. 裁判例検索**
- 検証済みURL: https://www.courts.go.jp/hanrei/search1/index.html
- 提供主体: 最高裁判所
- アクセス方式: HTMLスクレイピングのみ(API無し)
- データ形式: HTML+PDF
- ライセンス: 判決文自体は著作権法13条で著作権の目的外(再利用可)。サイトポリシーは最高裁独自(政府標準利用規約対象外)で要確認
- 更新頻度: 随時(下級審速報は2002年3月以降)
- KG化の価値: 判例-適用法条-裁判所-当事者類型の関係。法令KGに「解釈・適用」レイヤーを付与できる

**6. 官報発行サイト**
- 検証済みURL: https://www.kanpo.go.jp/
- 提供主体: 内閣府(発行: 国立印刷局)
- アクセス方式: バルクダウンロード(PDF、API未確認)
- データ形式: PDF(内閣府の電子署名・タイムスタンプ付き)
- ライセンス: 無料閲覧・DLは発行後原則90日間。過去分は2003年7月以降の法令等・2016年4月以降の政府調達をPDF公開。それ以外は有料サービス
- 更新頻度: 平日毎日
- KG化の価値: 官報発行法施行(2025年4月1日)により電子版が正本化。法令公布・叙位叙勲・破産公告・法人解散等、他ソースにないイベント情報源。ただしPDF抽出が必要で90日制約があるため日次収集アーキテクチャが必須

### B. 統計・データカタログ

**7. e-Stat 政府統計API(3.0版)**
- 検証済みURL: https://www.e-stat.go.jp/api/ (仕様: https://www.e-stat.go.jp/api/api-info/e-stat-manual3-0)
- 提供主体: 総務省統計局(各府省統計を集約)
- アクセス方式: API(REST、要利用登録・アプリケーションID)
- データ形式: XML/JSON/CSV
- ライセンス: e-Stat利用規約(政府標準利用規約準拠、出典明示で商用可)
- 更新頻度: 各統計の公表スケジュールに応じ随時
- KG化の価値: 統計表-地域-時点-指標の多次元データ。統計表メタ情報APIで統計調査の体系そのものもエンティティ化できる

**8. 統計LOD**
- 検証済みURL: https://data.e-stat.go.jp/lodw/ (エンドポイント: http://data.e-stat.go.jp/lod/sparql/alldata/query)
- 提供主体: 総務省統計局・独立行政法人統計センター
- アクセス方式: API(SPARQL 1.1 / GeoSPARQL)
- データ形式: RDF
- ライセンス: 政府標準利用規約準拠
- 更新頻度: 不定期(対象統計の追加時)
- KG化の価値: **カタログ中最もKGネイティブ**。地域コード・統計概念が既にURI化されており、自前オントロジーとのリンク先(外部語彙)として最優先で検討すべき

**9. e-Govデータポータル(旧DATA.GO.JP)**
- 検証済みURL: https://data.e-gov.go.jp/ (www.data.go.jp は301リダイレクトを確認)
- 提供主体: デジタル庁
- アクセス方式: API(CKAN標準API、メタデータ取得: https://data.e-gov.go.jp/data/api_guide)
- データ形式: JSON(DCAT準拠メタデータ)、データ実体はCSV/XLS/PDF等様々
- ライセンス: メタデータは政府標準利用規約準拠。個々のデータセットは各規約に従う
- 更新頻度: 随時(各府省の登録次第)
- KG化の価値: 全府省データセットのメタデータハブ。「どの省庁が何のデータを持つか」という組織-データセット関係自体がKGの1レイヤーになる。2023年3月31日にDATA.GO.JPを統合して公開

**10. e-Gov APIカタログ(メタソース)**
- 検証済みURL: https://api-catalog.e-gov.go.jp/
- 提供主体: デジタル庁
- アクセス方式: HTML(行政APIの横断カタログ)
- データ形式: HTML
- ライセンス: 政府標準利用規約準拠
- 更新頻度: 随時
- KG化の価値: 政府提供APIの公式一覧。本カタログの継続メンテナンス(新API発見)に使う運用ソース

### C. 法人・経済・知財

**11. gBizINFO**
- 検証済みURL: https://info.gbiz.go.jp/ (REST API v2仕様: https://info.gbiz.go.jp/html/index_v2_20250919.html)
- 提供主体: 経済産業省(デジタル庁と共同運営)
- アクセス方式: API(REST。2026年1月リニューアルでv2運用中と確認)。**SPARQLエンドポイントは2024年4月に提供終了**
- データ形式: JSON
- ライセンス: gBizINFO独自規約(要確認: https://info.gbiz.go.jp/api-spec/document/policy.pdf)
- 更新頻度: 随時(補助金・調達・表彰等の情報連携)
- KG化の価値: 法人番号をキーに補助金・調達実績・許認可・表彰・財務情報を統合済み。法人エンティティのリッチ化に最適。RSシステムの支出先とも法人番号で連結可能

**12. 法人番号公表サイト**
- 検証済みURL: https://www.houjin-bangou.nta.go.jp/ (Web-API: https://www.houjin-bangou.nta.go.jp/webapi/index.html / 全件DL: https://www.houjin-bangou.nta.go.jp/download/zenken/index.html)
- 提供主体: 国税庁
- アクセス方式: API(REST、要届出) + 全件バルクCSV
- データ形式: CSV/XML
- ライセンス: 政府標準利用規約準拠(商用・再配布可)
- 更新頻度: 全件データは月次(前月末時点)、差分は日次
- KG化の価値: 全法人(約500万件)の法人番号-商号-所在地。**KG全体の法人IDマスター**として必須。gBizINFO・EDINET・調達情報の名寄せキー

**13. EDINET API(Version 2)**
- 検証済みURL: https://disclosure2dl.edinet-fsa.go.jp/guide/static/disclosure/download/ESE140206.pdf (仕様書2026年6月版) / エンドポイント: https://api.edinet-fsa.go.jp/api/v2/documents.json
- 提供主体: 金融庁
- アクセス方式: API(REST、2023年8月21日よりAPIキー登録必須)
- データ形式: XBRL / CSV(UTF-16タブ区切り) / PDF
- ライセンス: EDINET利用規約(出典明示で利用可)
- 更新頻度: 平日随時(開示書類提出の都度)。API v2で2021年3月以降取得可
- KG化の価値: 上場企業の有価証券報告書から役員・大株主・子会社・セグメントの関係を構造化抽出できる。企業間資本関係グラフの最良ソース

**14. 特許情報取得API / J-PlatPat**
- 検証済みURL: https://www.jpo.go.jp/system/laws/sesaku/data/api-provision.html (手引き: https://ip-data.jpo.go.jp/files/ 配下)
- 提供主体: 特許庁(J-PlatPat運営はINPIT)
- アクセス方式: API(REST、試行提供・要利用者登録・アクセス数上限あり) + バルクデータ(公報等。有償/無償区分は要確認)
- データ形式: JSON/XML
- ライセンス: 特許庁独自規約(試行段階)
- 更新頻度: 公報発行に応じ随時
- KG化の価値: 特許-出願人(法人)-発明者-分類(IPC)の関係。五庁OPD経過情報も取得可。法人の技術ポートフォリオをKGに追加できる

**15. RESAS(地域経済分析システム)**
- 検証済みURL: https://opendata.resas-portal.go.jp/docs/api/v1/index.html (旧API文書)
- 提供主体: 経済産業省・内閣府
- アクセス方式: **APIは2025年3月24日提供終了**。サイトからのデータDLのみ
- データ形式: CSV
- ライセンス: RESAS利用規約
- 更新頻度: 随時(2026年1月にもメニュー更新)
- KG化の価値: 地域経済指標。ただしAPI廃止のため優先度低。元データはe-Stat等で代替可能

### D. 予算・調達・行政監視

**16. 予算書・決算書データベース**
- 検証済みURL: https://www.bb.mof.go.jp/hdocs/bxsselect.html
- 提供主体: 財務省主計局
- アクセス方式: バルクダウンロード
- データ形式: XML(一般会計・特別会計・政府関係機関) + PDF + Excel/CSV
- ライセンス: 政府標準利用規約準拠
- 更新頻度: 年次(予算・決算サイクル。昭和22年度以降収録)
- KG化の価値: 所管-組織-項-目の予算科目階層と金額。RSシステム(事業)・調達(契約)と繋ぐと「予算→事業→支出先」の資金フローKGが構築できる

**17. 行政事業レビュー見える化サイト(RSシステム)**
- 検証済みURL: https://rssystem.go.jp/ (CSV: https://rssystem.go.jp/download-csv)
- 提供主体: 内閣官房行政改革推進本部
- アクセス方式: バルクCSVダウンロード + Web検索UI
- データ形式: CSV
- ライセンス: 政府標準利用規約準拠
- 更新頻度: 年次(レビューサイクル、2021年度以降。サイトは2024年8月公開)
- KG化の価値: 全政府事業の事業-府省-予算額-**支出先(法人名・法人番号)**-成果指標。法人番号でgBizINFOと連結でき、政府資金フローKGの中核

**18. 調達ポータル(政府電子調達)**
- 検証済みURL: https://www.p-portal.go.jp/
- 提供主体: デジタル庁・内閣府(各府省の調達情報を集約)
- アクセス方式: Web検索UI + 調達情報等公開機能API(e-Gov APIカタログ掲載: https://api-catalog.e-gov.go.jp/info/ja/apicatalog/view/42)
- データ形式: HTML/CSV/XML(APIによる)
- ライセンス: 政府標準利用規約準拠
- 更新頻度: 日次(公告・落札の都度)
- KG化の価値: 入札公告-落札者-契約金額-発注府省。RSシステム・法人番号と組み合わせ官民取引関係を構築

**19. 官公需情報ポータルサイト**
- 検証済みURL: https://www.kkj.go.jp/ (APIガイド: https://www.kkj.go.jp/doc/ja/api_guide.pdf)
- 提供主体: 中小企業庁
- アクセス方式: API(検索API、登録不要)
- データ形式: XML
- ライセンス: 政府標準利用規約準拠
- 更新頻度: 日次(国・自治体の入札情報を集約)
- KG化の価値: 国+地方自治体の入札案件を横断取得できる唯一のAPI。調達ポータルより広い(自治体含む)

**20. 政治資金収支報告書**
- 検証済みURL: https://www.soumu.go.jp/senkyo/seiji_s/seijishikin/
- 提供主体: 総務省(+47都道府県選管に分散)
- アクセス方式: バルクダウンロード(PDF)
- データ形式: PDF(スキャン画像含む、OCR必要)
- ライセンス: 政府標準利用規約準拠だが公表期間の運用に注意(掲載期間経過後の削除あり、要確認)。自前アーカイブ必須
- 更新頻度: 年次(定期公表は毎年11月末)
- KG化の価値: 政治団体-寄附者(個人・法人)-政治家の資金関係。議員KGと法人KGを結ぶ独自レイヤーだが抽出コストは最大級

### E. 政策文書・人事

**21. 閣議決定・閣議案件**
- 検証済みURL: https://www.kantei.go.jp/jp/kakugi/ / https://www.kantei.go.jp/jp/kakugikettei/
- 提供主体: 内閣官房(首相官邸サイト)
- アクセス方式: HTMLスクレイピングのみ
- データ形式: HTML + PDF
- ライセンス: 政府標準利用規約準拠
- 更新頻度: 週2回(火・金の閣議ごと)
- KG化の価値: 閣議決定-政策文書-担当府省-日付。法案の閣議決定→国会提出→成立のイベントチェーンを構成する起点

**22. 各府省幹部名簿・閣僚名簿**

### F. 地理空間・防災

**26. 国土数値情報ダウンロードサービス**

- 更新頻度: データセットごとに年次程度
- KG化の価値: 行政区域・施設・鉄道・土地利用等の地物エンティティと行政区域コード。KGの空間バックボーン

**27. 国土地理院(地理院タイル・地理院地図API)**

- 更新頻度: 随時

**28. アドレス・ベース・レジストリ**

### H. データモデル・語彙(データではなく設計基盤)

**35. GIF(政府相互運用性フレームワーク)+ IMI共通語彙基盤**
- 検証済みURL: IMI: https://imi.go.jp/ (稼働確認済み) / GIFコード類はデジタル庁サイトとGitHubで公開
- 提供主体: GIF=デジタル庁 / IMI=IPA(経産省系、サイトは存続)

- データ形式: RDF/XML/JSON-LD/スプレッドシート

- 更新頻度: IMIコア語彙の更新は事実上停止気味。コード・コードリストはGIF側で更新(2024年8月版を確認)。**語彙の新規策定はGIFへ移行済みと判断**
- KG化の価値: オントロジー設計の直接の参考。IMIコア語彙(人・組織・場所・イベント等)とGIFのデータモデル記述書・コード体系(府省コード・地方公共団体コード等)は自前オントロジーの土台にできる。ただしIMIの将来性に依存しない設計(参照はするがフォークする)を推奨

## 要件定義への示唆(結論)

1. **IDバックボーン**: 法人番号(法人)・アドレス・ベース・レジストリ(住所)・行政区域コード(地域)・法令番号(法令)の4つが名寄せキー。オントロジーはこの4IDを一級市民にすべき。
2. **資金フローKG**が最も価値が高い接続: 予算書XML→RSシステムCSV(事業・支出先法人番号)→gBizINFO/調達ポータル→EDINET。全て機械可読で繋がる。
3. **法令ライフサイクルKG**: パブコメ→閣議決定→国会審議(会議録API)→官報公布→e-Gov法令API v2(時点管理)→裁判例。イベントチェーンとして設計可能。
4. PDF層(官報・政治資金・審議会)はLLM抽出パイプライン前提でコスト見積りを分けること。官報は90日以内の日次収集が運用要件になる。
