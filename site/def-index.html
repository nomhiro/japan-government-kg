日本政府ナレッジグラフ オントロジー

Japan Government Knowledge Graph (JGKG) — 語彙定義

このプロジェクトは日本国政府とは無関係です。 日本国政府が公開するデータを第三者が構造化したものであり、政府による公式なデータセットではありません。

一次データの出典は各名前付きグラフに機械可読な形で保持しています。判断の根拠には必ず一次資料をご確認ください。

政府が公開するデータを横断して接続するためのオントロジーです。誰が・何を・どこで・いつ・いくらで・何について、の6軸を基底クラスに置き、関係は出来事(Event)を介して表すことで時点の情報を落とさない設計にしています。

語彙

モジュールURI内容
core /def/core 6軸の基底クラスと、出典を表す用語
org /def/org 組織・府省。法人番号を正準IDに使う
law /def/law 法令と改正イベント。法令IDを正準IDに使う
budget /def/budget 予算事業と支出。府省→予算事業→支出先法人の縦スライス
all /def/all 全モジュールの統合(SHACL検証用)

用語のURIはハッシュURIです。/def/core#Agent のように参照し、フラグメントを外した /def/core がオントロジー本体を返します。SHACL形状は /def/all.shacl.ttl にあります。いずれも text/turtle で配信し、CORSを開けています。

専門用語を避けた日本語の表示名は dcterms:title(@ja)にあります。skos:prefLabel ではありません——各用語は既に skos:definition(定義文)と skos:inScheme(SKOS概念としての所属)を持つため skos:prefLabel を探しがちですが、こちらは付けていません。

識別子

実体の識別子は /id/org/{法人番号}、出典グラフは /graph/{ソース}/{取得日} の形です。これらはまだ解決しません。 SPARQLエンドポイントの公開後に対応します。

現在の状態

法令→府省→予算事業→支出→法人の縦スライスを実データ(884,052クアッド)で構築済みです。出典付きスナップショット、名前付きグラフでの出力、SHACL検証ゲート、成果物ビルドと提供の経路が動き、検索・エンティティ詳細・近傍サブグラフ・パス探索のアプリから参照できます。

設計書・調査レポート・進捗状況は GitHub リポジトリ にあります(日本語)。KG本体のダウンロードは GitHub Releases から取得できます。
